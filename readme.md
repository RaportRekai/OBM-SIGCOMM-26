
## **Generating Alpha vs. Throughput Plots**

This branch contains scripts for generating **Alpha vs. Throughput** plots for **Workload A** and **Workload B**.

To generate the plots, navigate to each workload directory and execute the corresponding Bash script.

### **Workload A**

```bash
cd workload-A
bash bash_script.sh
```

### **Workload B**

```bash
cd workload-B
bash run.sh
```

Upon successful execution, the scripts generate the corresponding figures in **PDF format**.
